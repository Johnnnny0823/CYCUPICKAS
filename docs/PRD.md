# PRD

## 產品背景
中原選課時，課綱資訊分散在個別頁面，學生比較課程成本高。

## 使用者痛點
學生要逐一開課綱找課程內容、評分方式、先備要求與作業產出，容易遺漏重點。

## AS-IS
查詢課程列表，點進每門課綱，人工閱讀與比較。

## TO-BE
在課程列表直接點「AI 幫你監」，展開本地整理後的摘要卡。

## 目標使用者
正在比較中原課程的學生與展示評審。

## 功能需求
Chrome Extension 掃描課程列、比對課程代碼、顯示摘要、評分方式、先備知識、課程產出與補充搜尋。

## 非功能需求
不登入、不讀個資、不呼叫外部 AI API、可由非工程隊友照 README 展示。

## 資料需求
`課程資料.xls/csv`、公開課綱 HTML、本地人工修正檔。

## 本地預處理與規則解析分工
Python 工具負責轉檔、驗證、抓取、解析與合併；Extension 只負責前端呈現。

## 不做的功能
不代選課、不搶課、不判斷甜課難度、不蒐集教師評價。

## 驗收標準
Demo 可開、Extension 可載入、按鈕可注入、摘要卡可展開、資料流程可重跑。

## 未來擴充
接入更多學期、改善課綱 HTML parser、加入人工審核介面。
