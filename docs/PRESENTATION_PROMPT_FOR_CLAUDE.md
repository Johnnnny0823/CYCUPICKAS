# 「AI 幫你監」成果發表簡報大綱生成 Prompt（給 Claude Opus 4.8 / Claude for Design 使用）

> 用途：複製本檔全文貼給 Claude（建議 Opus 4.8 模型，或 Claude for Design），請它依此規劃 10 頁簡報大綱，再據以產出簡報。以下內容已依 `cycu_pick_assit` 專案真實背景填寫，不是空白範本。

---

## 你的角色

請你扮演一位**資深軟體產品經理與簡報專家**，協助我為「AI 幫你監」系統的成果發表製作一份簡報大綱。

## 專案背景

- **系統名稱**：AI 幫你監（中原大學選課輔助 Chrome Extension）
- **目標受眾**：課程教師 / 專題評審（大學專題成果發表場合，聽眾具備基本科技素養但非全為工程背景）
- **專案核心痛點**：中原大學選課系統把課綱資訊拆散在每一門課各自的頁面裡，學生要一門一門點開課綱，才能看到評分方式、先備知識與課程產出，比較多門課的成本很高，容易漏看重點（例如漏看某堂課其實有期末報告）。
- **系統核心價值**：把「逐門課手動翻課綱」的比價流程，改成在課程列表上一鍵展開本地整理好的摘要卡，並可多課並排比較、依「沒報告／沒考試／沒作業」快速篩選——全程在瀏覽器本機完成，不登入、不連外部 AI API、不碰個資、不代選課搶課。

## 簡報結構要求

請規劃 **10 頁**簡報架構，**每一頁都必須包含以下三個部分**：

1. **投影片標題**：具備結論性，不是單純的分類標籤
   - ❌ 不要：「模組介紹」「系統架構」
   - ✅ 要像：「摘要卡把選課比較從『開 N 個分頁』縮成『點一下展開』」
2. **視覺化建議**：這頁適合用什麼圖表或畫面呈現（例如：AS-IS/TO-BE 流程對照圖、系統架構圖、Demo 截圖、比較表截圖、篩選前後對照、資料處理管線圖）
3. **講者備忘錄**：3–4 點條列講稿重點，說明這頁要強調什麼、帶出什麼效益

## 具體內容大綱（10 頁）

- **第 1 頁**：破題首頁（標題「AI 幫你監」與主講人／團隊資訊）
- **第 2 頁**：專案背景與痛點——選課時課綱資訊分散、人工比較耗時且容易遺漏評分方式等重點
- **第 3 頁**：解決方案與系統架構——本機資料管線（課程資料 → course_seed → 課綱抓取解析 → course_summaries）＋ Chrome Extension 前端注入呈現，兩者分工清楚、不需登入不連外部 AI API
- **第 4 頁**：核心功能模組一——AI 摘要卡（一鍵展開課程摘要、評分方式表格、先備知識、課程產出、資料來源狀態、原始課綱連結）
- **第 5 頁**：核心功能模組二——多課比較與 AI 篩選（最多 3 門課並排比較；依「沒報告／沒考試／沒作業／課綱已解析」快速篩選）
- **第 6 頁**：關鍵成果與量化數據（**請留空由我自行填入實測數據**，例如：涵蓋課程數 58 門、資料驗證通過率、預期節省的課綱查閱時間等）
- **第 7 頁**：使用者體驗回饋（或操作簡便性展示）——強調操作路徑短（列表 → 點按鈕 → 摘要卡展開）、支援收合側欄擴大可視表格、長文字自動折疊不撐爆版面
- **第 8 頁**：未來擴充計畫與願景——接入更多學期資料、改善課綱 HTML parser 辨識率、加入人工審核介面、逐步降低對 `manual_overrides.json` 人工修正的依賴
- **第 9 頁**：Q&A 與總結——重申系統邊界（不代選課、不搶課、不判斷「甜課」難度、不蒐集教師評價、只做 Google 搜尋連結導流）與核心價值
- **第 10 頁**：聯絡資訊與感謝

## 語氣要求

請用**專業、精煉、具說服力**的語氣生成這份大綱，避免空泛形容詞，優先使用具體行為描述（例如「從開 6 個分頁比較，變成同頁展開＋並排比較表」優於「大幅提升效率」）。

## 補充素材（可直接引用的系統事實，避免杜撰數據）

- 展示範圍：本機模擬課程列表頁（`fake_selection_system.html`）＋ Chrome 未封裝擴充功能，實測涵蓋 58 門課程（大一 15、大二 16、大三 20、大四 7）。
- 資料處理管線：Excel/CSV 課程資料 → 課綱網址驗證 → 課綱 HTML/PDF 抓取 → 規則解析（BeautifulSoup＋關鍵字，非呼叫外部 AI）→ 摘要 JSON → 驗證腳本把關。
- 系統明確不做的事：不代選課、不搶課、不判斷甜課難度、不蒐集或呈現教師評價（僅提供 Google 搜尋連結）、不登入、不讀個資、不呼叫外部 AI API。
- 目前已知限制（誠實揭露，可用於第 8 頁或 Q&A 備問）：部分課綱頁面可讀取但不含可解析關鍵字；同課程代碼多列資料時摘要以課程代碼共用；自動解析效果不足時仰賴人工覆寫檔 `manual_overrides.json` 修正。
