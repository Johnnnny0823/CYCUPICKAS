# Word Report Draft

## 計畫目的
本作品旨在降低學生閱讀課綱與比較課程資訊的成本，協助學生在選課前更快掌握課程重點。

## 問題背景
選課列表通常只提供課名、教師、時間與餘額等欄位，評分方式與課程內容仍需逐一開啟課綱頁面查看。

## 現行流程 AS-IS
學生查詢課程後，逐門點開課綱，人工閱讀課程目標、進度與評分表，再回到列表比較。

## 瓶頸分析
課綱內容可公開取得，但呈現位置分散；學生在短時間內比較多門課時容易漏看關鍵資訊。

## 改善後流程 TO-BE
本作品不是替代校方選課系統，而是在既有課程查詢流程之上，補足課綱資訊理解與比較決策的瓶頸。系統透過 Chrome Extension 形式，在不改動原系統、不要求帳密、不碰個資的前提下，將課綱中已存在但不易快速取得的資訊整理為摘要卡，使學生能在同一頁面快速查看課程內容、評分方式、先備知識與課程產出。本版本不使用外部 AI API，而是針對少量真實課綱資料進行本地驗證、抓取、解析與人工校正，確保展示資料可控且可追溯。

## 系統功能介紹
系統在課程列新增「AI 幫你監」按鈕，點擊後展開摘要卡，顯示課程摘要、評分方式、先備知識、課程產出與補充搜尋。

## 本地預處理與規則解析分工
資料處理由 Python 工具完成，包含 Excel 轉 JSON、URL 驗證、HTML 抓取、HTML 解析與人工覆蓋合併。

## 技術架構
前端採 Chrome Extension MV3；資料以 JSON 靜態檔提供；Demo 以本機 HTTP server 展示。

## 資料處理流程
使用者提供課程資料後，系統產生課綱 URL，先驗證可讀性，再抓取 HTML 並用規則解析欄位。

## 介面設計
介面維持校園工具風格，按鈕小巧，不遮蔽原本課表；摘要卡以清楚分區呈現。

## 隱私與倫理設計
不登入、不要求帳密、不讀個資、不顯示教師主觀評價，不輸出甜課、難度或信心分數。

## 作品特色
以 Extension 疊加既有流程，不改校方系統；資料來源可追溯；不依賴外部 AI API。

## 預期效益
降低課綱查閱時間，讓學生快速比較課程資訊，提升選課決策品質。

## 限制與未來發展
公開課綱頁可能未開放或格式不固定；未來可擴充更多學期、改善 parser 與人工審核流程。

## 結論
AI 幫你監以最小侵入方式補足選課資訊理解瓶頸，適合作為競賽展示與後續校園工具原型。
