# Demo Script

1. 說明痛點：學生選課時要逐一點開課綱，才能找到評分方式與課程內容。
2. 打開 `http://localhost:8765/demo/fake_selection_system.html`。
3. 說明此頁是仿介面，頁面本身沒有摘要。
4. 在 Chrome 開發者模式載入 `extension/`。
5. 回到課程列表，點某門課旁的「AI 幫你監」。
6. 展示「這堂課在幹嘛」。
7. 展示評分方式表格；若未解析成功，說明系統不猜測比例。
8. 展示先備知識與課程產出。
9. 點「加入比較」，展示右下「比較清單」按鈕與彈窗比較表。`n10. 點 AI 篩選，展示「沒報告」、「沒考試」、「沒作業」與「課綱已解析」。`n11. 點「補充搜尋」，展示只產生 Google 搜尋連結。
12. 收尾：本作品不登入、不改校方系統、不碰個資，只做前端決策輔助。
